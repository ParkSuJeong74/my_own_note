# Delivery roadmap

## Gate 0 — Repository and evidence

- Self-contained monorepo and validation command
- Product vision and requirements catalog
- Architecture boundary and ADR process
- Legacy intake inventory and source-of-truth map
- Threat model, data classification and backup objectives drafts

Exit: the folder can be copied elsewhere and its validation still runs without the parent repository.

## Gate 1 — Dependable personal editor

- Dark desktop workbench shell with collapsible explorer, active-document tab and save status
- Page tree, blocks, commands, keyboard navigation and accessibility
- Durable automatic save, local offline log, reconnect and conflict UX
- Undo/redo, revisions, archive/restore, import/export and backup restore test
- Search, tags, references and basic files
- Responsive desktop, phone and tablet flows

Exit: daily writing for four weeks without data loss or returning to a legacy notes screen.

## Gate 2 — Configurable workspace

- Typed databases and row pages
- Table, List, Board, Calendar, Gallery and Timeline
- Filters, sorting, grouping, relations, rollups and formulas
- Templates, action buttons, reminders and notification inbox
- Calendar, ledger and configurable dashboard examples

Exit: current Todo, Notes, Calendar and workspace boards can be rebuilt without application code.

## Gate 3 — Legacy capability adapters

- T1, blog, automation and monitoring data-source contracts
- Read and action permissions, refresh, errors and retry
- Editable templates reproducing existing Mano workflows
- Contract comparisons between legacy screens and user-built pages

Exit: every legacy page has a verified replacement including mutations, not only display parity.

## Gate 4 — Legacy retirement

- Import or adapter decision for every legacy dataset
- Backup, rehearsal, reconciliation report and rollback
- Hide old navigation, observe, then remove old UI routes
- Keep required collectors, jobs and alerts behind platform-owned contracts

Exit: the new platform is the only daily UI and no required workflow depends on legacy UI code.

## Gate 5 — Hosted multi-user platform

- Authentication, tenant isolation, permissions and account lifecycle
- Collaboration, presence, comments, mentions and activity
- Operational SLOs, abuse prevention, support and compliance foundations

## Gate 6 — Publishing and social

- Explicit page publication and themes
- Blog, subscriptions, SEO and scheduled publishing
- Social graph, reactions, comments, resharing, messaging and moderation

## Gate 7 — Commercial features

- Donations or billing only after legal, tax, refund, app-store and privacy review
- Sales treated as a separate product and compliance program

Gates are evidence-based and do not map directly to historical `m1`–`m7` labels.
