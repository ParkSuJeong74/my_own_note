# Architecture decision records

Create one Markdown file per consequential decision using `NNNN-short-title.md`.

Required sections:

1. Status
2. Context and constraints
3. Considered options
4. Decision
5. Consequences and risks
6. Rollback or replacement path
7. Validation evidence

No framework, database, editor engine, realtime algorithm, queue, or native shell is considered
selected until its ADR is accepted.
