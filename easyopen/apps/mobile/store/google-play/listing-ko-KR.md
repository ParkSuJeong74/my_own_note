# Google Play 등록 문구 — ko-KR

## 앱 이름

EasyOpen

## 짧은 설명

PC에서 실행 중인 Jellyfin을 같은 Wi-Fi에서 더 쉽게 연결해 보세요.

## 자세한 설명

EasyOpen은 복잡한 오픈소스 프로그램을 더 쉽게 시작하고 이용하도록 돕는 앱입니다.

현재 Android 베타에서는 PC의 EasyOpen에서 실행 중인 Jellyfin 서버를 등록하고, 연결 상태를 확인한 뒤 EasyOpen 내부 화면에서 이용할 수 있습니다.

- 여러 PC의 Jellyfin 주소를 저장하고 기본 서버 선택
- 연결 전에 서버 응답 상태 확인
- 같은 서버 주소 안에서만 이동하는 내부 화면
- 연결 정보를 기기 안에 저장

Android 앱이 Jellyfin 서버를 직접 설치하거나 실행하지는 않습니다. 영상이 저장된 Windows 또는 Mac에서 Jellyfin 서버를 먼저 실행해야 하며, 휴대폰과 PC가 같은 사설 Wi-Fi에 연결되어야 합니다.

CosyVoice는 Android에서 제공하지 않습니다. 현재 CosyVoice 후보는 NVIDIA GPU가 있는 Windows Desktop 전용으로 검증 중입니다.

EasyOpen은 Jellyfin 또는 CosyVoice 공식 프로젝트가 아니며 각 프로젝트의 보증이나 승인을 받았다고 주장하지 않습니다.
